2026-10-16：Windows 原波形界面采集，Jetson 仅同步控制

需求确认
用户希望减轻 Jetson 内存与计算负担，取消 Ubuntu 的 EMG 接收、绘图、处理和保存；随后明确选择保留 Windows 原有波形界面。按这一选择实现新入口，不继续扩展独立流式桥接。

备份优先
改动前备份本机原波形源码、旧独立启动脚本、旧桥接代码和完整中文工作日志。GitHub 根 README/.gitignore/提交号另存本地基线。原源码和旧启动脚本完成后再次计算 SHA256，与备份一致。新增文件集中在 outputs/emg_control_only；没有覆盖实验原始数据、令牌、SDK 或许可证。

核查
读取 GitHub Ubuntu 最新基线 6320378018f5b6d30d50eed722a78396e2ac5c60。确认旧 Ubuntu worker 会构造处理器、七路历史缓存、波形和 CSV；统一周期记录器固定保留七路 EMG 列。读取 Windows on_start/on_stop、FileSaveManager 和同步脉冲，发现原本地保存总开关为 False。

实现
新增原波形程序的内存适配启动器，开启本地处理后 CSV 和周期写入，输出目录改到本交付目录 records；原项目源码不变。控制服务使用 8766、独立控制协议，固定令牌从现有私有配置读取。SDK 仍由原程序持有；网络线程不采样，只经有界队列在 Qt 主线程调用原开始/停止。增加共享实例互斥，避免与旧桥接同时占用基站。

Ubuntu 新模块只含状态与指令，不构造 EMG 处理器，不画波形。默认联动关闭，可由用户勾选；Collect All 仅连接 EMG，Record 时请求 Windows 本地保存，停止时获取最终保存回执。安装器修改两处原模块、加入两个新模块；先核验源文件 SHA256/替换位置，先备份再安装，写入失败恢复旧文件。统一周期数据移除七路 EMG 的 42 列，不再为其逐周期生成空数组与输出列。

同步与边界
保留运行 UUID、两端事件时间、四时间戳时钟探测、Windows GUI 同步脉冲、CSV 路径和设备时间基准。平时仅约 2 秒一次状态，运行每分钟三次时钟探测。断线不会停止 Windows，重连可取回原运行编号并停止。软件指令同步不等于硬件采样同步；设备内部延迟未知，原程序独立模式中的 label_zero_perf_ns/actual_sync_start_perf_ns 为 null 时原样保留。本次不宣称解决物理样本精确对齐，也没有恢复 raw SDK JSONL 旁路。

最终 5 项软件集成测试通过：控制指令防重复、零波形传输、断线续采/重连停止、远程开关、Qt worker 仅写控制事件、安装前备份与原记录器无 EMG 列输出（多个断言归于五项测试）。原波形程序的模拟端到端测试通过：本地 CSV 3207 数据行、513407 字节；断线期间继续采集，STOP 后保存成功，旁证带设备时间基准。全部新增 Python 通过编译检查。
