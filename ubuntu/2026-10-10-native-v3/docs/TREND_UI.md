# V3.4 轻量趋势显示与实测

## 使用

启动命令不变：`python3 hipexo_monitor19.py`。本次调整电机、IMU和力传感器页面。显示目标8 Hz，每条曲线最多160点；分桶保留极值，包含无效值的桶保留断线空档。不会修改原生CSV、采集频率、1000 Hz同步网格或300 ms记录周期。极值显示不是抗混叠滤波或离线科学分析数据。

IMU默认显示姿态三图，选择框可切换加速度、角速度或全部九项。隐藏页面不重画，全部九项模式负载更高。四路在线/断线卡片保留，状态周期检查为0.5秒。

底部每秒检查CSV是否增长，显示“正在记录”、文件大小、“等待文件增长”（3秒未变化）或写入错误。它表示写入活动，不保证每路设备在线或数据已经fsync；设备状态和pipeline_quality仍需同时查看。

## 验证

17项自动测试通过：显示点上限、端点顺序、窄峰/NaN空档、输入不变、IMU视图选择、录制增长/停止/错误、IMU断线恢复/调零及处理流水线。

真实X11 1920×1080窗口持续可见，电机零输出监测、四IMU和双路力同时记录，页面每30秒切换。完整有效核心180秒。本次没有测试EMG、相机和LiDAR；不是再次10分钟耐久测试。

| 指标 | 上次10分钟 | 本次3分钟 |
|---|---:|---:|
| 电机实际重画/秒 | 6.49 | 6.02 |
| IMU实际重画/秒 | 1.67（九图） | 3.55（三图） |
| 力实际重画/秒 | 4.22 | 5.90 |
| 采集进程组RSS采样峰值 MiB | 524.64 | 506.25 |

这是不同时间、时长和IMU视图下的实测对照，不能把全部差异归因于代码，也不能声称所有页面达到8 Hz。电机没有变快；IMU和力的趋势刷新改善。RSS每10秒采样，非瞬时峰值；从启动448 MiB升至缓冲热身后约506 MiB，末次502 MiB，最小系统可用内存2384.6 MiB。短测不能排除更长期内存问题。

四IMU各200 Hz；两路力各1000 Hz；电机998.85/999.08 Hz。全部八路最大原生间隔小于10 ms。有效核心1000 Hz网格180000行，各路缺失标记均0；记录881624帧（包括热身/退出），迟到、乱序、记录队列溢出和缓冲溢出均0，队列峰值497024字节。电机发送与有效反馈计数各自一致，CRC坏字节和发送错误0。此处IMU频率指寄存器读取率，电机时间戳为主机校验完成时间。
