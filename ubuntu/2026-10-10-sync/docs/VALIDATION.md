# 验证记录（2026-10-10）

## 验收口径

- 能原生采集 1000 Hz 的优先原生采集；不能达到时保留实际时间与速率，再重采样到统一 1000 Hz。
- 每周期 300 行，每 60 行一个片段，共 5 片段。300 ms 分包同时用于释放旧内存；网络等候窗口另有固定上限。
- 看原始样本数、实际间隔、迟到/乱序、队列溢出、图片写入数、内存走势和停止时排空结果。生成一个完整 CSV 不等于所有传感器都完整。

## 已执行

- 57 项原界面、四路 IMU 状态与参考姿态、EMG 处理/网络/时钟、文件管理回归测试通过。
- 14 项新管线、IPC 退出错误、插值/断档/角度边界、抗混叠、相机隔离、ADC 量程回读与通道顺序测试通过。
- 四只 IMU RRATE 均设为 200 Hz，写入并回读确认。两路 I²C 是 400 kHz / 100 kHz；设备输出频率不等于主机实读频率。
- ADS8688 手动流水选通有效；SPI 合并事务的实验出现第二路无效结果，已拒绝采用。现在每帧保持独立片选，时间戳取实际读取完成时刻。
- ADS8688 量程编码按官方低四位定义修正，并回读验证；4 MHz SPI 可读取。需用已知电压和重量复核实际参考电压/载荷标定。
- 电机仅测试零输出反馈，300 次/端口均通过 SDK 校验；单端口请求应答中位约 1.98 ms、平均约 2.13 ms（约 469 Hz 最大连续读取速率）。双电机现有串行轮询约 203 Hz。USB 延迟计时器已是 1 ms。没有把电机配置数值 1000 当成实际采样率。
- SDK 包装新增释放 GIL 的调用，等待串口时其他 Python 线程可继续。命令对象/反馈对象由锁保护；SDK 校验失败不把旧反馈记录成新样本。

## 真实联采的范围

真实测试包含四路 IMU、两路力传感器和相机缺席重连；最后又加入两台电机的零输出反馈。原始文件只留本机。最新压力负载下约 IMU 175/175/123/123 Hz，力传感器两路约 831 Hz。先前同机不同负载下 IMU 达到约 183/183/134/134 Hz。不能承诺当前 I²C/操作系统链路稳定达到 IMU 200 Hz 或力传感器 1000 Hz。

力传感器不等待的连续读取短测曾达到约 1117–1271 Hz/路，但间隔有毫秒级抖动；这只证明平均吞吐量有余量，不证明恒定 1 ms 周期。ADS8688 芯片 500 kSPS 能力充足，当前瓶颈在主机 SPI 调用和调度。

当前未发现 RealSense；图像链路使用模拟深度图测试。未重新连接真实 Windows Delsys，也未测试真实 LiDAR 或带负载电机控制。不要把模拟全通道压力测试当成这些硬件的验收。

## 持续压力测试

正常负载 180 秒全通道模拟压力测试通过：2,142,000 条源样本、3,000 张 640×480 规则模拟深度图全部写入，迟到/乱序/溢出均为 0，停止后 0.76 秒排空。后段父进程 RSS 约 43.8 MiB、写盘进程约 90.4 MiB；这不包含完整 Qt/torch 界面的基础内存。统计见 `synthetic_stress_180s.json`。再用含随机深度扰动的图像测试 60 秒，714,000 条源样本与 1,000 张图全部写入，0 迟到/乱序/溢出，排空约 0.75 秒；末段写盘进程约 92.5 MiB，输出约 477 MB。见 `synthetic_stress_noise_60s.json`。最终队列水位和错误自动停录修改已包括在该轮测试中。

开发过程中曾在并行编译/回归等负载下触发有界队列满；错误会报告记录不完整，不会无限吃内存。不能保证任意额外负载下零丢失。

## 进一步达到硬件稳定频率

I²C-1 当前 100 kHz；要更接近四路各 200 Hz，需核对线缆/上拉与控制器 400 kHz 配置，可能涉及设备树和重启。若要求力传感器严格等间隔 1 ms，应使用 ADC 外部硬件定时/带缓存采集控制器或评估实时采集驱动；普通 Linux 用户态轮询即使平均 1000 Hz 也有调度抖动。当前版没有更改设备树、内核或电机固件。

## 复现方法

在 `python/` 目录运行：

```bash
QT_QPA_PLATFORM=offscreen python3 -m unittest test_pipeline test_force_capture test_recording_process test_pipeline_integration test_camera_isolation
mkdir -p evidence
python3 benchmark_pipeline.py --seconds 180 --isolated --images --cycles-callback --output evidence/synthetic_stress.json
python3 generate_simulated_example.py --output ../examples/SIMULATED
```

压力测试只生成模拟数据，临时采集文件结束后清理，只保留统计报告。需留出足够临时磁盘空间；不连接硬件。默认图像为规则深度渐变，不能代表复杂真实深度图的最坏编码负载。

旧接口回归需 `HIPEXO_RECORDING_MODE=legacy HIPEXO_VISION_MODE=inference QT_QPA_PLATFORM=offscreen`，并在导入测试前先把 `--preview` 加入 `sys.argv` 后导入 `hipexo_monitor`，确保测试不会访问真实设备。
